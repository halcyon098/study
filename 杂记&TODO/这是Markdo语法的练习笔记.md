 ### 2.4 列表

##### 无序列表

​	可以使用*，+，-，标记标签；来表示无序列表项， **但要在标记后加空格**，语法为

*第一项

+第二项

-第三项

* 第一项

  + 第二项

  - 第三项

##### 有序列表

可以使用数字加上“ . ” 再加空格来表示有序列表

1. 第一项

2. 第二项

3. 第三项

##### 嵌套列表

* 一
  * 1.1
    * 1.1.2

* 二
  * 2.1
    * 2.1.1

可以在有序列表内嵌套无序列表也可以在无序列表内嵌套有序列表。

### 2.6引用代码

如果是一行代码，可以使用段内码块来表示，用一对`（数字1旁边的符号）来括住代码。

比如 `printf("hello world!");`

如果是代码段，那么可以使用三个`加 **Enter/空格+代码**来表示，如：

``` java
public One{
    public static void main(Strig[] args){
        System.out.println("hello world");
    }
}
```
