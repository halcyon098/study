## 💻 模块一：代码审计 - Java 安全与 .NET 安全 (4 周)

### 📚 理论与工具 (第 1-2 周)

- **Java：**
  - **重点：** **Spring Framework** 和 **Java 反序列化**（如 Jackson, fastjson, Commons-Collections）。
  - **学习内容：** **污点分析 (Taint Analysis)** 原理；JavaEE 中的**过滤器/拦截器**安全配置。
  - **工具：** 熟练使用 **IDEA/Eclipse** 调试代码；使用 **Fortify / Checkmarx** 等静态分析工具进行实践。
- **.NET：**
  - **重点：** **ASP.NET Core/MVC** 的工作机制；**反序列化**（如 `BinaryFormatter`, `Json.NET`）。
  - **学习内容：** `.NET` 配置文件安全；**依赖注入 (DI)** 框架的安全问题。
  - **工具：** 熟练使用 **Visual Studio** 调试代码；使用 **Rider** 或其他相关审计工具。

### 🛡️ 实战与深度 (第 3-4 周)

- **Java 深度：** 关注 **高权限操作**（如 JNDI 注入、文件上传、SSRF 的绕过）。
- **.NET 深度：** 关注 **权限提升**（如配置错误导致的特权操作、高危 API 的滥用）。
- **实践：** 至少审计两个 **实际项目**（可选择开源项目或公司非核心代码）。

## 🛠️ 模块二：武器化开发 - Go 语言 CEX 工具 (4 周)

### 🏗️ 基础与框架 (第 5-6 周)

- **Go 语言精进：** 重点掌握 **并发编程**（`Goroutines`, `Channels`），提升工具的扫描速度和稳定性。
- **工具架构：** 设计工具的**模块化架构**：**命令行接口 (CLI)**、**网络通信模块**、**结果报告模块**。
- **核心开发：** 使用 `flag` 或 `cobra` 库处理命令行参数；开发 **HTTP/TCP** 通信模块。

### ⚙️ 核心功能与实战 (第 7-8 周)

- **CEX 核心功能实现：**
  - **多协议支持：** 实现 **HTTP/HTTPS** 代理、自定义 Headers。
  - **PoC/Exp 集成：** 设计 **插件式** 的 PoC/Exp 接口，便于后续添加新漏洞利用。
  - **漏洞模块：** 优先实现**反序列化 Payload 生成和发送**、**文件读取/上传**模块。
- **交付：** 一个 **可运行** 且具备**多线程**、**基础漏洞利用能力**的 Go 语言 CEX 工具 **Beta 版**。

## ☁️ 模块三：内网渗透与云安全 (4 周)

### 🏰 内网渗透 (第 9-10 周)

- **Windows AD：** 重点学习 **Kerberos 协议**、**域内信息收集**、**横向移动技术**（如 Pass-the-Hash, Kerberoasting）。
- **Linux：** 学习 **权限维持**（如 Rootkit 基础）、**SUID/Capabilities** 滥用。
- **实战工具：** 熟练使用 **Impacket** 套件、**Mimikatz**、**Cobalt Strike** (或开源替代品) 的基础功能。
- **实践：** 在 **VulnHub/TryHackMe/Hack The Box** 等平台完成至少 **2 个** 内网渗透靶场。

### 🛡️ 云安全 (第 11-12 周)

- **基础概念：** 理解 **IAM** (身份和访问管理)、**安全组/VPC**、**对象存储** 的安全配置。

- **重点攻击面：** **权限升级**（IAM 策略配置错误）、**SSRF**（针对云元数据服务）、**存储桶配置错误**。

- **学习平台：** 重点选择一个云平台（如 **AWS** 或 **Azure**）进行深入学习。

- **工具：** 学习使用如 **Pacu** (AWS) 或 **ScoutSuite** 等云安全审计工具。
