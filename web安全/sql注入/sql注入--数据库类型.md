## Access

使用asp的网站，常用数据库为access、sqlserver。

Microsoft Access 是一种关系型数据库管理系统，可用于存储、管理和检索数据。虽然Access通常用于较小的数据库和单服务器环境，但它也可以用于大型企业和互联网应用。

此外,Access与其他数据库管理系统（如MySQL、SQL Server等）在处理SQL注入方面有所不同。

现在使用这种数据库的网站极少，一般只有比较旧的网站会使用

### 特性

- 没有数据库用户
- 没有数据库权限
- 没数据库查询参数
- 没有高权限注入这个说法

因此只能进行基于字典暴力猜解（你能自己才出来也行，不过基本没戏）

### 注入方法

1. 联合注入
2. 偏移注入

**偏移注入的产生主要是用来解决表名猜到，列名猜不到的情况**，偏移注入是一种注入姿势，可以根据一个较多字段的表对一个少字段的表进行偏移注入，一般是联合查询，在页面有回显点的情况下

在SQL注入的时候会遇到一些无法查询列名的问题，比如系统自带数据库的权限不够而无法访问系统自带库。

当你猜到表名无法猜到字段名的情况下，我们可以使用偏移注入来查询那张表里面的数据。

像Sqlmap之类的工具实际上是爆破字段的名字，但是如果字段名称比较奇葩，就无可奈何了

**注入原理**：

> 假设一个表有8个字段，admin表有3个字段。
>
> 联合查询payload：union select 1,2,3,4,5,6,7,8 from admin 
>
> 在我们不知道admin有多少字段的情况下可以尝试payload：union select 1,2,3,4,5,6,7,admin.* from admin，此时页面出错
>
> 直到payload：union select 1,2,3,4,5,admin.* from admin时页面返回正常，说明admin表有三个字段，8-5=3
>
> 然后通过移动admin.*的位置，就可以回显不同的数
