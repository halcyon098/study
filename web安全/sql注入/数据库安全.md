## mysql

端口：3306

一般php搭建的网站喜欢用MySQL

爆破：

mysql默认配置本地登录root用户

远程的连接请求拒绝的

mysql借助phpmyadmin猜解

phpmyadmin第三方的数据库管理应用搭建在对方的服务器的

phpmyadmin登录mysql数据库，这个数据发送是由本地到本地的过程所以可以进行测试
