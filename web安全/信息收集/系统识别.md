# 系统识别

在web渗透测试前期信息收集中需要收集服务器的信息。分为Windows和Linux，在Windows系统不区分大小写，Linux中会对大小写有严格的限制。

eg:访问xxx.com/index.php时将路径改为xxx.com/index.phP时Windows系统可以正常访问，Linux系统会报错。这可能关系到后面的漏洞利用。

通过ping命令查看返回的TTL字段值可以大概判断系统，但是不准确，因此不常用。

常用的是使用工具收集系统信息，例如使用namp，使用命令：

```shell
namp -O ip
```

工具会返回服务器的类型和版本信息。还可以通过工具查看端口开放情况，以此判断服务器部署的服务。namp返回的状态中，filtered指由于报文无法到达指定端口，namp不能决定端口的开放情况，但可以判断服务器使用的数据库。因为不同数据库默认的端口不同。
