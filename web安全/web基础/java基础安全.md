## 逻辑漏洞
密保问题
当传递的是键值名和键值值时，当代码编写逻辑出现问题时，修改数据包，传递数据库中不存在的键值名取出来的是空值，我们人为将不存在的键值名赋空值时可能会使代码判断逻辑通过，使我们可以绕过密保类问题造成安全隐患。
修复建议：修改请求数据只传递值将键名写死或其他方法避免被篡改。
