# CDN绕过

## 判断是否有CND服务

使用在线超级ping工具，若出现多个IP，即判断目标启用了cdn服务

## 绕过

1. 解析子域名(未启用范域名，例如加速域名为,*.baidu.com)，子域名一般极有可能与主站在同一IP
2. 历史cdn记录，有可能查看到未启用cdn服务时的真实IP
3. 国外请求（加速区域为国内），网站开启的cdn服务加速区域是国内，使用国外请求会请求到真实IP
4. 网络空间引擎搜索法（仅加速网站某个服务，例如图片），使用搜索引擎查找历史记录，可能会在网站其他服务中解析出真实IP，搜索引擎有：zoomeye, fofa, shodan
5. cdn本身，使用社工等手段得到控制面板的账号密码。（概率不大）

### 漏洞&遗留文件

使用php环境建站，可能会遗留一个phpinfo.php文件，这个测试文件会暴露网站的真实IP，php版本，和一些主机信息等敏感信息。要注意是否有内网网卡，不然解析的是内网地址。可以在在线IP工具上验证一下。

ssrf漏洞，利用漏洞让目标服务器主动连接自己的服务器，在日志中会记录访问IP，这个IP一般会是真实IP
