# 数据库初识

## 一，基本语法

数据库语法不区分大小写。在 phpMyAdmin 中创建一个名字叫 **user** 的数据表，数据表有4项信息，uid,username,gender(性别),brief(简介)。

### 1.1 增

`INSERT INTO table_name(column1,column2,...) VALUES (value1,value2,...);`

INSERT INTO user(uid,username,gender,brief)  VALUES (1, "张三", 1, "我不是法外狂徒的那个张三");

### 1.2 删

`DELETE FROM table_name [WHERE Clause];`

DELETE FROM user WHERE uid=1;     

WHERE 后面跟条件。上面的意思是在user表里删除 uid=1 的数据项，也可以不加WHERE和后面的条件。

### 1.3 改

`UPDATE table_name SET field1=new-value1, field2=new-value2 [WHERE Clause];`

UPDATE user SET username = “王晓美” WHERE uid = 2; //将 user 表中 uid=2 的 username项改为"王晓美"

UPDATE user SET username = “王晓美 2 号” , gender = 3 WHERE uid = 2;//将 user 表中 uid=2 的 username项改为"王晓美二号"，gender(性别)改为未知性别 3 。

### 1.4 查

`SELECT column_name,column_name FROM table_name [WHERE Clause];`

SELECT * FROM user;//查找并显示user表的全部，“* ”代表全部。

SELECT user.username FROM user WHERE uid = 2;//查找user表 uid=2的项，且仅显示username项。

## 2.1 MySQLi - 面向对象

```php
<?php
```

## 2.2 MySQLi - 面向过程

```php

$username = "root"; //用户名
```

## 2.4 增删改查配合

1. **造一个 mysqli 对象，造连接对象**
1. **准备一条 SQL 语句**
1. **执行 SQL 语句,如果是查询语句。成功返回结果及对象**
1. **判断返回是否有内容,执行成功**
1. **如果成功了，从结果集对象里找到数据**
1. **返回索引数组**

### 2.4.1 增

```php
<?php
//存入数据库相关数据
$servername = "localhost"; //域名
$username = "root"; //账户名
$password = "123456"; //密码
$dbname = "myDB"; //数据库名
$port = "3306"; //数据库端口

// 创建连接
$conn = new mysqli($servername, $username, $password, $dbname ,$port);

// 检测连接
if ($conn->connect_errno) {
    die("连接失败: " . $conn->connect_error);
}

//存入sql语句
$sql = "INSERT INTO user (username, gender, brief) VALUES ('李四', 0, '嘿嘿嘿')";

//判断插入是否成功
if ($conn->query($sql) === TRUE) {
    echo "新记录插入成功";
} else {
    echo "Error: " . $sql . "<br>" . $conn->error;
}

//释放链接
$conn->close();
?>
```

## 2.5，增删改查（面向对象预处理）

### **预处理参数类型：**

• i – integer 整形

• d – double 双浮点

• s – string 字符串类型

• b – BLOB blob 类型(二进制)

### **2.5.1 增** 

```php
<?php

header('content-type:text/html;charset=utf-8');$servername = "localhost"; //域名

$username = "username"; //账户名

$password = "password"; //密码

$dbname = "myDB"; //数据库名

$port = "3306"; //数据库端口

//创建连接

//实例化mysqli对象,连接 mysql 数据库

$mysqli = new mysqli($servername, $username, $password, $dbname,

$port);

if ($mysqli->connect_errno) {

die($mysqli->connect_error);

}

$mysqli->set_charset('utf8'); //设置字符集

$sql = "insert into user(username,brief) values(?,?)";

$mysqli_stmt = $mysqli->prepare($sql); //准备预处理语句

$username = "小明同学";

$brief = "一个很有好的同学";

//s代表 string 类型

$mysqli_stmt->bind_param('ss', $username, $brief);

//执行预处理语句

if ($mysqli_stmt->execute()) {

echo $mysqli_stmt->insert_id; //程序成功，返回插入数据表的行id

echo PHP_EOL;

} else {

echo $mysqli_stmt->error; //执行失败，错误信息

}

//释放结果集

$mysqli_stmt->free_result();

$mysqli_stmt->close();

$mysqli->close();
```
