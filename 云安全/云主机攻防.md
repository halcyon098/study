## 概念

“云主机”（Cloud Server），又称云服务器，是云计算服务体系中的一项核心产品。简单来说，它就像是一台放置在远程数据中心、通过互联网租给你的“虚拟电脑”。

以下是对云主机及其核心概念的深度拆解：

------

### 1. 什么是云主机？

在传统时代，如果你想运行一个网站，你需要买一台物理服务器。而**云主机**是利用**虚拟化技术**（Virtualization），将成千上万台物理服务器集群化，形成一个巨大的“资源池”，再从这个池子里划分出独立的虚拟单元。

#### 云主机的通俗比喻：

- **物理服务器**：像买了一套独栋别墅。你需要自己修屋顶、接水电，如果房间不够住，只能再盖一栋。
- **云主机**：像租住高级公寓。水电物业（硬件维护、网络）由物业公司（云厂商）负责。如果你觉得房间小了，打个招呼就能瞬间升级成大户型（增加配置）。

------

### 2. 核心技术概念

理解云主机，需要掌握以下几个关键词：

- **虚拟化 (Virtualization)**：这是云主机的灵魂。它让一台物理机器可以同时运行多个相互隔离的操作系统。
- **弹性伸缩 (Elasticity)**：这是云主机最大的优势。你可以根据流量大小，随时增加 CPU、内存或带宽，而不需要停机更换硬件。
- **分布式存储 (Distributed Storage)**：你的数据通常不是存在某一块硬盘上，而是切碎后保存在不同的物理节点上，即使某块硬盘坏了，数据也不会丢失。
- **高可用性 (High Availability)**：如果承载你云主机的物理机出故障了，云系统会自动将你的主机迁移到另一台正常的机器上，保证业务不中断。

------

### 3. 云主机的优势 vs 传统服务器

| **特性**     | **云主机**             | **传统物理服务器**         |
| ------------ | ---------------------- | -------------------------- |
| **部署速度** | 几分钟内完成创建       | 购买、运输、组装需要数天   |
| **成本投入** | 按需付费，无硬件折旧   | 初始投入高，有闲置浪费风险 |
| **可靠性**   | 集群备份，故障自动迁移 | 单机故障即业务中断         |
| **扩展性**   | 点击鼠标即可升级配置   | 需停机并手动插拔硬件       |

------

### 4. 常见的云主机应用场景

1. **网站/APP 后端**：支撑日常访问流量。
2. **开发测试环境**：快速搭建、测试完即销毁，极具性价比。
3. **大数据处理**：利用多台云主机并行计算海量数据。
4. **学习研究**：学生或开发者用来练习 Linux 系统、搭建个人博客。

------

### 5. 著名的云服务商

目前市面上主流的厂商包括：

- **国际**：亚马逊 AWS (Amazon Web Services)、微软 Azure、Google Cloud。
- **国内**：阿里云 (Alibaba Cloud)、腾讯云 (Tencent Cloud)、华为云。

## 注意

云主机通常会分配两个IP，一个内网IP，一个外网IP，内网IP负责在云环境的lan中进行主机之间的通信，当需要访问互联网的时候才会使用外网IP。

安全组
安全组（SecurityGroup）是一种有状态的包过滤功能的虚拟防火墙，它用于设置单台或多台云服务器的网络访问控制，可以将同一地域内具有相同网络安全隔离需求的云服务器实例加到同一个安全组内，通过安全组的网络策略对云服务器的出入流量进行安全过滤。



各个云厂商一般都会在实例，主机中默认有agent用来收集流量，监控主机状态。

卸载方法：

阿里云官方文档：https://help.aliyun.com/zh/security-center/user-guide/uninstall-the-security-center-agent



## 攻击思路

- 阅读产品文档、阅读架构文档、了解相关操作手册，了解产品功能模块
- 常规渗透一样子域名查找、端口扫描、目录扫描、指纹识别等，在查找的过程中留意AccessKey等密钥，会在APK文件、Github关键词、Web页面、JS文件、常规配置文件
- 云主机的应用漏洞（SSRF、RCE、本地文件读取等常规漏洞）
- 云产品的默认配置
  - OSS文件存储服务，默认设置为开放，导致文件任意下载
  - 端口默认对外0.0.0.0/0公网开放

渗透场景中拿到ak/sk后使用官方给的open api文档进行操作利用，或者别人已经写好的图形化工具。

官方文档中还提到了另一种利用场景，使用ssrf漏洞去读取实例的元数据。
